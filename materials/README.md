# Materials

Datasheets of the components used in the testbench, kept here so that the bill
of materials can be checked without chasing external links.

| File | Component |
|---|---|
| `ABX00162-ABX00173-datasheet.pdf` | Arduino UNO Q board |
| `ABX00162-full-pinout.pdf` | Arduino UNO Q pinout |
| `ABX00162-schematics.pdf` | Arduino UNO Q schematics |
| `AOD4184A.pdf` | N-channel power MOSFET, PWM output stage |
| `max31865.pdf` | RTD-to-digital converter for the PT100 sensors |
| `TEC RC3-2.5.pdf` | Reference thermoelectric module datasheet |

The installed cell is a generic 16 mm Bi2Te3 module. It was characterised in
situ rather than taken from a datasheet, because it could not be removed from
the assembly. The RC3-2.5 datasheet is included as the reference profile the
measured parameters were compared against.
